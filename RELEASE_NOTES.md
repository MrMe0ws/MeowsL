# Релиз 0.5.0

## Вариант для GitHub Releases

## ✨ Главное окно

- **У MeowsL появилось главное окно** — открывается при запуске программы и по клику на иконку в трее
- **Главная** — видно сразу, работают ли хоткеи и установлены ли языковые пакеты OCR. Раньше это можно было узнать только командой в PowerShell
- **История** — последние 50 переводов по дням: скопировать в буфер или открыть заново в окне перевода. Закрытый popup больше не теряет перевод навсегда
- **Горячие клавиши** — вся шпаргалка в одном месте, плюс перезапуск от администратора и перерегистрация хоткеев, если после сна что-то отвалилось
- **Настройки** — автозапуск, языковая пара, задержка перевода, язык распознавания и поведение окна перевода
- **О программе** — проверка обновлений и диагностика: Python, OCR, связь с переводчиком, права

Крестик **×** сворачивает окно в трей — программа продолжает работать. Выход по-прежнему только через меню трея.

## ✨ Улучшения

- **Распознавание русского текста с экрана** — раньше OCR работал только с английским. Язык выбирается в настройках, есть режим «Авто»
- **Клавишу перевода с экрана можно переназначить** — если `Ё` конфликтует с консолью в игре
- Задержку перед переводом, языковую пару и поведение popup теперь можно настроить
- Звуковой сигнал после распознавания текста с экрана

## 🐛 Исправления

- В панели задач и трее показывается логотип MeowsL, а не иконка Python

## ⚠️ При обновлении

- Закройте старый MeowsL через иконку в трее, затем замените файл на `MeowsL_0.5.0.exe`
- **Автозапуск теперь тихий**: при старте Windows окно не появляется, MeowsL сразу уходит в трей. Включить показ можно галочкой «Открывать это окно при запуске» в настройках
