# Релиз 0.4.0

## Вариант для GitHub Releases

## ✨ Улучшения

- **Ресайз с углов** — окно перевода можно тянуть сразу по ширине и высоте, как обычные окна Windows: за любой из четырёх углов плашки
- Если Google Translate снова замолчит, MeowsL сам пробует запасной переводчик

## 🐛 Исправления

- **Перевод снова работает** — длинные фразы больше не падают с ошибкой «No translation was found using the current translator»
- Сообщения об ошибке перевода стали короткими и понятными, без простыни исходного текста

## ⚠️ При обновлении

- Закройте старый MeowsL через иконку в трее, затем замените файл на `MeowsL_0.4.0.exe`
