# Релиз 0.3.2

## Вариант для GitHub Releases

## 🐛 Исправления

- **Ctrl+C+C после долгого сна** — хоткей снова работает без перезапуска: модификаторы проверяются через Win32 `GetAsyncKeyState`, а не через «залипшее» состояние `keyboard.add_hotkey`
- То же для запасного **Ctrl+Alt+T**

## 🧱 Технические изменения

- `Ctrl+C` / `Ctrl+Alt+T` переведены на хуки по scan code (как клавиша Ё) + проверка Ctrl/Alt из ОС
- Усилен `power_resume`: скрытое окно с HWND, подписка на suspend/resume и разблокировку сессии Windows
- Сборка: артефакт с версией в имени — `MeowsL_0.3.2.exe`
