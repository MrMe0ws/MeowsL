# Релиз v0.3.0

## Вариант для GitHub Releases

## 🚀 Новое

- **Перевод с экрана по клавише Ё** — нажмите физическую клавишу "Ё", обведите текст рамкой мышью и получите перевод в модалке
- **Оверлей выделения** — затемнение экрана, пунктирная рамка, отмена по `Esc`
- **Модалка рядом с выделением** — окно перевода открывается под, над или сбоку от выбранной области (с учётом границ экрана)

## ✨ Улучшения

- Хоткей **Ё** привязан к физической клавише (scan code 41) и работает независимо от раскладки
- Распознавание текста с экрана через встроенный **Windows OCR** (английский пакет)


## 🧱 Технические изменения

- Новые модули: `screen_capture_overlay`, `ocr`, `ocr_runner`
- Зависимости: `winocr`, `Pillow`
- Обновлены `build/meowsl.spec` (сборка WinRT/OCR), `README.md`, `requirements.txt`
