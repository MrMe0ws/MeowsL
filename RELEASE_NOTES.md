# Релиз v0.3.1

## Вариант для GitHub Releases

## 🐛 Исправления

- **Хоткеи после сна Windows** — `Ctrl+C+C` и `Ctrl+Alt+T` снова работают без перезапуска: при пробуждении системы хоткеи переподключаются автоматически

## 🧱 Технические изменения

- Новый модуль `platform/power_resume.py` — обработка `WM_POWERBROADCAST` и переподключение хоткеев
- `HotkeyListener.restart()` со сбросом залипшего состояния библиотеки `keyboard`
- Улучшено завершение фоновых потоков перевода и OCR (`translation_runner`, `ocr_runner`)
